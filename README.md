# Dispomix-Sib AI Chatbot

Чат-бот для подбора антикоррозионных покрытий Dispomix и генерации коммерческих предложений.

## Установка и запуск локально
1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`
3. Установите переменные окружения:
   - `DEEPSEEK_API_KEY` — ключ API DeepSeek (если нужна NLP).
   - `BACKEND_URL` — URL бэкенда (по умолчанию `http://localhost:8000`).
4. Запустите сервер: `uvicorn main:app --host 0.0.0.0 --port 8000`.

## Деплой на Render
1. Создайте новый Web Service, укажите этот репозиторий.
2. В разделе Environment добавьте переменную `DEEPSEEK_API_KEY`.
3. Сервис автоматически подхватит конфигурацию из `render.yaml`.
4. После деплоя укажите публичный URL в переменной `BACKEND_URL` и перезапустите сервис.

## Встраивание на сайт
Добавьте файл `chat_widget.html` как HTML-блок на вашем сайте (Craftum или другой). Настройте в коде виджета URL бэкенда.
